# dataset1 物理门控诊断（2026-11-10）

**结论：门控参数确实训练了，但普通设备边已近乎常数化；动态训练后，M3和补偿边也更接近固定缩放。六维物理输入的连续变化只带来很小的额外策略收益。**

## 方法与数据

使用 `outputs/GNN+gate_set1/static/checkpoints/best.pt`（20,000回合）与动态最佳（8,500回合），统一CPU单线程推理；每个模型分别完成100个动态验证实例，静态模型另外完成100个静态实例。原checkpoint与训练输出只读，诊断存入独立目录。

每个决策只对适用门控的工序／关系组采样一次，去掉正反边和同类多设备的重复项；不把结构边或阶段不适用边的固定1混入统计。静态验证每组48,829个样本，静态模型动态验证每组48,926个，动态模型动态验证每组43,652个。连续时间步样本相关，不把这些样本数当作独立实验重复数。

适用边占全轨迹所有边快照的6.27%（静态）及5.88%（动态），说明门控只在限定阶段作用；不能将此比例直接当作消息贡献比例。

## 门值与状态敏感度

每格依次为四个attention head。标准差按float64汇总。

| 模型／边组 | 门值均值 | 门值标准差 |
| --- | --- | --- |
| 静态／普通 | .98955, .96112, .99821, .89123 | .000038, .000059, .000012, .000017 |
| 静态／M3 | .90184, .97495, .91120, .92484 | .00164, .00257, .00168, .00475 |
| 静态／补偿 | .93667, .94150, .92455, .92202 | .03057, .02947, .01660, .00943 |
| 动态／普通 | .98908, .96307, .99825, .91255 | .000003, .000004, .000001, .000001 |
| 动态／M3 | .92175, .98007, .94892, .93990 | .00057, .00089, .00085, .00139 |
| 动态／补偿 | .97848, .97905, .96969, .95083 | .00437, .00420, .00386, .00327 |

门值均偏高，没有大量接近0的强抑制，更多是弱衰减。普通组输出几乎不变，尤其第三head接近恒为1。动态训练后，补偿边均值向1靠近、波动减小。

六维输入并非恒定：各组对应动态样本的特征标准差约 .440、.239、.420、.241、.260、.439。普通门控不变不能归因于输入未变化。

普通组门控头中间Tanh的采样激活 **100%满足绝对值>.95**，静态和动态均如此；输出对物理输入的局部导数很小，说明该头进入饱和区。动态M3／补偿头对应占比约28.6%／34.0%。这个>.95是诊断阈值，并非严格梯度为0。

补偿组对“当前补偿裕量”最敏感，其次包括“当前间隔是否用过M3”；这是局部导数和样本标准差得到的敏感度描述，不是因果重要性。静态补偿组已用／未用M3时均值分别约 [.9201,.9257,.9150,.9168]／[.9630,.9666,.9397,.9303]；动态变成 [.9775,.9781,.9688,.9500]／[.9814,.9818,.9723,.9531]，区分明显减弱。

## 固定策略干预

保持全部权重不变、适用mask不变，替换门值后完整重新运行同一100例动态验证集：

1. 原门控：使用六维物理信号计算门值。
2. 固定均值：各组／各head使用原轨迹的平均门值，移除连续物理信号调制，但保留阶段mask和组别。
3. 全1：取消门值衰减；其它网络权重保持原样。

| 使用的模型 | 原门控 | 固定均值 | 全1 |
| --- | ---: | ---: | ---: |
| 静态最佳→动态验证 | 34.2505 | 34.2304（改善.059%） | 34.3888（变差.404%） |
| 动态最佳→动态验证 | 34.1906 | 34.1954（变差.014%） | 34.2776（变差.254%） |

动态模型固定均值后，只有1／100例目标变化；全1有36／100例变化。静态模型固定均值有10／100例变化，全1有46／100例变化。

固定均值保留当前阶段mask，不能据此认定全部物理上下文无用；它直接支持“六维信号的连续调制贡献很弱，当前模块主要表现为组／head固定缩放”。全1变差说明网络已经适应这套缩放，并不证明重新训练的无门控网络会更差。

按输入固定事件轨迹分组，动态模型纯故障10例的均值从35.6842降至全1的35.0172，改善1.87%；但无事件和释放子集变差，导致总体全1更差。该现象是同权重下的场景取舍，样本小，不能推出所有故障情况应关闭门控。

静态最佳与动态最佳在统一动态验证上的总体均值为34.2505→34.1906，改善约.175%。CPU复评与训练时GPU验证存在小幅数值差异（动态记录34.2063）；不能混用设备记录计算干预收益。

## 建议与边界

- 先把“组／head可训练常数＋阶段mask”作为轻量对照，检验六维网络是否值得保留。
- 若继续物理自适应设计，优先处理普通门控头Tanh饱和，并将共享编码器与层独立门控头分开验证；不要同时叠加FiLM再归因。
- 本次没有重新训练模型、修改物理定义或调整参数。门值敏感度与干预均不能证明物理信号理论上无用，结论限定于这两个checkpoint与dataset1验证分布。

原始逐实例数据、样本NPZ、门值分位数、关联、局部导数及干预表：`outputs/GNN+gate_set1/diagnostics_20261110/report.json`。诊断代码为 `scripts/analyze_physical_gate.py`。
