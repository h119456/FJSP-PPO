# PPO-RS 工厂规模合成数据集 dataset2

`dataset2`是保留原`data/dataset`后新增的较大规模合成数据集，由`scripts/generate_dataset2.py`使用固定种子`20261030`生成。

## 数据规模

- 训练集：1000个实例；
- 验证集：100个实例；
- 测试集：200个实例；
- 每个实例包含12～20个工件；
- 每个工件包含5～10道顺序工序；
- 每个实例包含6～10台普通加工设备、1台M3和1台M4；
- 每道普通工序具有2～5台候选设备。

## 参数范围

除规模外，物理、时间、成本和目标函数范围与现有`data/dataset`一致：

- 普通加工时间：1.5～5.0；
- 饱和变形参数A：0.18～0.45；
- 变形速率参数B：0.080～0.250；
- M3时间：0.26～0.78，成本：0.12～0.48；
- M4/原机补偿时间：0.6～1.2，成本：0.1～0.4；
- 强制补偿阈值：0.30；
- 最小停留变形比例：0.5；
- 补偿后变形比例：0.10～0.20；
- 目标权重：Makespan为1.0，M3成本为0.5，补偿成本为0.5。

该数据集用于真实规模训练流程和网络扩展验证，但参数仍是合成参数，不代表已经由真实工厂测量标定。

## 重新生成

```powershell
python scripts/generate_dataset2.py
```

## 训练

```powershell
$env:PYTHONPATH = "src"
python -m ppo_rs.train --config configs/dataset2.json
```
